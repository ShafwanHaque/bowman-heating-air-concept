# Bowman Heating & Air Concept — HVAC Website

A standalone Next.js concept project tailored to Bowman Heating & Air. It includes the full `src` app and pnpm lockfile.

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project notes

- Business details, palette, services, coverage, and calls to action are in `src/config/site.config.ts`.
- The website presents the brand as a wordmark; a restrained text-only SVG wordmark accompanies the official service-truck hero image from www.callbowman.com. Internet access is required to load those source assets.
- The request form is a preview and does not send submissions. The service-area map uses OpenStreetMap tiles and needs internet access.
- Confirm all business details before publishing.

Original website: https://www.callbowman.com/
